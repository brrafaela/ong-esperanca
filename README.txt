PROJETO ONG ESPERANCA

Este projeto e uma landing page para a ONG Esperanca, desenvolvida como atividade academica com foco em front-end, design responsivo e experiencia do usuario.

VISAO GERAL

A iniciativa tem como objetivo apresentar a organizacao, divulgar seus projetos sociais e permitir que pessoas interessadas em colaborar preencham um formulario de cadastro. O site foi estruturado com paginas separadas para apresentacao, projetos e cadastro de voluntarios.

ESTRUTURA DO PROJETO

- index.html: pagina inicial com apresentacao da ONG, missao e formas de ajudar.
- projetos.html: pagina dedicada aos projetos e campanhas sociais.
- cadastro.html: formulario de cadastro para voluntarios e apoiadores.
- css/style.css: estilos gerais do site, incluindo layout, botoes, cards, formulario e responsividade.
- JS/main.js: inicializacao das funcionalidades do front-end.
- JS/router.js: gerenciamento de navegacao e exibicao de conteudos.
- JS/modules/: arquivos com validacao, armazenamento local e navegacao.
- imagens/: pasta com as imagens locais do projeto.

TECNOLOGIAS E RECURSOS

- HTML5 semantico com header, nav, main, section, article e footer.
- CSS responsivo para visualizacao em desktop, tablet e celular.
- JavaScript para validacao de formularios e armazenamento local de cadastros.
- Formulario com validacao nativa de campos (required, email, tel, cpf e padroes).
- LocalStorage para guardar os cadastros enviados.
- Layout com cards, botoes, alertas e componentes visuais para melhorar a interface.
- Java: o projeto tambem e contextualizado no ambiente academico com uso de Java como linguagem de apoio ao estudo de logica, estruturas de dados e desenvolvimento de solucoes em programas orientados a objetos.

IMAGENS E ASSETS

A pasta imagens/ contem os arquivos locais utilizados no site, como logo da ONG e imagem ilustrativa de solidariedade. Essas imagens sao carregadas com tags picture e srcset para oferecer melhor compatibilidade entre formatos, como AVIF, WEBP e JPEG.

Exemplo:

<img src="imagens/logo_ong.jpeg" alt="Logo da ONG Esperanca">

O projeto nao depende de imagens externas para funcionar corretamente.

EXECUCAO

Para visualizar o site, basta abrir o arquivo index.html em um navegador ou utilizar um servidor local simples, como o Live Server, caso esteja trabalhando em um editor como VS Code.

OBSERVACOES

Este e um projeto academico, com foco em front-end e experiencia do usuario, mas com a possibilidade de evoluir para integrações futuras com backend, banco de dados e tecnologias como Java em aplicacoes mais completas.
